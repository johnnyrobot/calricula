# Publish `workspace-ui` to GitHub Packages and finish Calricula host Task 8

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** Make `@applicationx/workspace-ui` installable by Calricula from GitHub Packages (owner decision 2026-09-19: private registry, not public npm), then execute the deferred host-plan Task 8 so `/programs/[id]/collaboration` renders the shared `WorkspaceShell` (workspace content arrives in P2 through `renderWorkspace`).

**Architecture:** GitHub Packages requires the package scope to equal the repository owner, so the package is renamed `@johnnyrobot/workspace-ui` (the `@applicationx` scope stays as the UI/theme prefix only). A tag-triggered workflow in the ApplicationX repo publishes with `GITHUB_TOKEN` (`packages: write`). Calricula maps the `@johnnyrobot` scope to `https://npm.pkg.github.com` in a committed `.npmrc` (registry mapping only — never a token); CI and the production Docker build inject a read token at install time. Deployers building Calricula from source need a token with `read:packages` (documented as the cost of the private-registry decision).

**Spec:** EMBEDDED-INTERFACE §6 (tailwind content path, `--ax-*` token overrides, re-exports, `WorkspaceShell` wiring, smoke test). Revised 2026-09-20: the package is `0.2.0` and ships no chat surface.
