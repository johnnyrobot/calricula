# ApplicationX P2–P4 roadmap and plan outlines

Date: 2026-09-17 (revised 2026-09-20) | Status: Scoped outlines, not implementation plans

These phases stay in scope exactly as the [PRD](../PRD.md) §10 defines them.
Each outline lists the deliverables, the gate that unlocks it, the tasks a full
plan will expand (bite-sized, test-first), and the acceptance cases from
[TECHNICAL-SPEC](../TECHNICAL-SPEC.md) §12 it must satisfy. A full plan is
written for a phase only after the previous phase's exit checklist is green.

## P1 — foundation (implemented)

Identity, organizations, workspaces, program mappings, host-context handshake,
row-level security, connector contract with `lmi.lookup`, workspace UI package,
standalone entry, Calricula host route. Delivers AX-01–AX-04.

## P2 — employer collaboration, evidence graph, cross-app proposals

**Delivers:** AX-05 through AX-10; the same features in both hosts; one
end-to-end employer-feedback-to-review action.
**Unlocks when:** pilot programs mapped; manual employer entries approved as
the source (no directory or posting licence required); owner decision on the
CTE compliance evidence candidate requirement.
**Expands into tasks:**

1. Data model migrations: `Employer`, `EmployerLocation`, `Contact` (with
   source, obtained-at, consent, opt-out and suppression), `JobPosting` /
   `Opportunity`, `Entity` / `ExternalIdentity`, `Claim` with valid-time and
   observed-time, relationship tables for the §4 vocabulary,
   `Thread` / `Message` / `Artifact` with audiences, `AgentRun` / `ToolCall` /
   `Approval`, `Job` / `OutboxEvent` / `DeliveryReceipt`; RLS policies for every
   private table.
2. Program revision counter in Calricula (`Program.revision`, bumped in the
   update route) so `context_stale` and AX-09 rebase checks use a monotonic
   value instead of `updated_at`.
3. Workspaces API (`/v1/workspaces`, threads, tasks, artifacts) with ETag
   revision tokens and 409 conflict views; SSE workspace event streams at
   `/v1/workspaces/{id}/events` (Calricula's broker already relays them); the
   Calricula `/collaboration` selector lists authorized workspaces.
4. Employer records with explainable relevance factors (never a hiring
   probability), duplicate-branch handling, posting status observations,
   outreach drafts that require an `Approval` bound to content hash, recipients,
   revision and expiry, and that carry a physical address and opt-out by default.
5. Occupation and regional connectors: `occupations.lookup` (O*NET,
   CareerOneStop) and `regional.index` (Centers of Excellence / EDD), consumed
   as published with attribution.
6. Evidence graph queries in PostgreSQL (recursive CTEs, bounded depth/size/
   time), exact-vs-inferred identity, unmerge, invalidation of derived claims on
   mapping change; table/narrative rendering first, graph canvas optional.
7. Coordinator agent with named workflows (research, curriculum, advisory,
   review), typed tool grants, budgets (20 calls, 5 minutes, configured
   monetary cap), cancellation, and the `queued → … → completed` state machine.
8. Exchange packages: `POST /v1/exchanges` validator/receiver stub; Calricula
   receiver that creates a draft review item and never overwrites an approved
   COR; Calipar receiver plan handed to that repository; package dedupe by
   `package_id`; `delivery_unknown` reconciliation.
9. Embedded host: P2 package release exposes employer records, threads, tasks,
   evidence and approvals through `WorkspaceShell.renderWorkspace`; Calricula
   pins the new version.
10. If accepted: CTE compliance evidence — advisory roster with Title 5 §55601
    role categories, structured meeting records with sign-in capture, ≥1/year
    indicator, and a Perkins V needs-assessment (Element #6) export.

**Acceptance:** Graph, Employers, Collaboration, Agents and Exchanges rows of
TECHNICAL-SPEC §12; PRD §9 staff usefulness and work-reduction pilot measures
recorded with denominators.

## P3 — private student workflows

**Delivers:** AX-11, AX-12.
**Unlocks when:** institutional private-data permissions, user credential flow,
retention policy and permitted model processing are configured (TECHNICAL-SPEC
§13). Lack of credentials is not completion.
**Expands into tasks:**

1. `PrivateStudentProfile`, opt-in sharing, applications, interview-outcome,
   placement and alumni follow-up records excluded from the public graph;
   deletion within 24 hours across objects, search and providers.
2. Employer-verified competency signals on a student profile, sourced from the
   advisory loop (`EMPLOYER_CONFIRMS_TASK`), with the evidence trail.
3. Work-based-learning activity model (placement type, hours, supervisor,
   paid/unpaid) and an integration target for experiential-learning platforms.
4. Competency pilot measures (AX-12): assessment/rubric revision, assisted vs
   independent conditions, cohort denominators, missing follow-up.

**Acceptance:** Private-workflows row of §12; isolation negative tests with
student and employer principals.

## P4 — scale evaluation

**Unlocks when:** the PostgreSQL graph benchmark (p95 under 2 s for the five
core questions at 100,000 entities and 1,000,000 claims on pilot hardware) has
been run.
**Expands into tasks:**

1. Benchmark harness comparing PostgreSQL and a candidate Neo4j projection on
   identical data; adopt the projection only for public records and only if
   the target fails after indexing and bounded traversal work.
2. Optional specialist subruns and additional messaging channels only after
   measured need.

**Acceptance:** restore exercise validating RPO 24 h / RTO 8 h before
production onboarding.

## Cross-phase rules

- Every phase plan ends with a requirement-to-task table and an exit checklist
  file in the ApplicationX repository (`docs/P<n>-EXIT.md`).
- Calricula changes stay small and separately reviewable: P2 program revision
  counter and exchange receiver, nothing else planned.
- No phase converts synthetic, demo or fallback values into institutional facts;
  Calipar imports keep `origin=real|demo|synthetic`.
- No phase promises a complete employer list or posting history.
